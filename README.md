# The Advanced SQL Server Masterclass For Data Analysis

SQL practice for Travis Cuzick’s [Udemy course](https://www.udemy.com/course/advanced-sql-server-masterclass-for-data-analysis/).

## Database

[Download the full AdventureWorks2019 backup](https://github.com/miqyd0104/SQL-practice/releases/download/adventureworks2019/AdventureWorks2019.bak) from this repository’s release. The backup is Microsoft’s [AdventureWorks2019 OLTP sample](https://learn.microsoft.com/en-us/sql/samples/adventureworks-install-configure#download-backup-files).

Restore the backup to SQL Server as `AdventureWorks2019`, then select that database in VS Code before running the queries.
